# Vicky's Klothing

Website for Vicky's Klothing, custom-made dresses in Chantan, Lapaz.

## Publish with GitHub Pages
1. Create a new repository on github.com (e.g. `vickys-klothing`).
2. Upload `index.html`, `README.md` and the `images/` folder (drag and drop works).
3. Go to Settings > Pages, choose Branch: `main`, folder `/ (root)`, and Save.
4. Your site goes live at `https://<your-username>.github.io/vickys-klothing/`.

## Command line
```
git init
git add .
git commit -m "Add Vicky's Klothing website"
git branch -M main
git remote add origin https://github.com/<your-username>/vickys-klothing.git
git push -u origin main
```
